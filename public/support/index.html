Questions fréquentes

Faut-il un compte ? Non. Vos données restent sur votre appareil.

L'app fonctionne-t-elle hors ligne ? Oui, une fois installée.

Comment effacer mes données ? Le bouton « Se déconnecter » efface toutes les données de l'app sur l'appareil.

Version web : https://mohamadalhabib92.github.io/famcal/ — sur iPhone ou iPad, ouvrez-la dans Safari puis Partager → « Sur l'écran d'accueil ».
